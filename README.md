# ONE LIFE — UE5 Foundation

This is the clean Unreal Engine foundation for the real game, replacing the earlier HTML prototypes.

Engine target: Unreal Engine 5.8.

Included:
- C++ third-person character foundation
- Enhanced Input hooks
- interaction interface
- continuous world time subsystem
- physical/mental needs component
- persistent life-memory data model
- single-player GameMode
- rendering defaults for Lumen/Nanite/Virtual Shadows
- Chaos Vehicles plugin enabled
- StateTree/Mass foundations enabled for future NPC/crowd work
- art direction, vertical-slice specification and systems roadmap

Important: this is source architecture, not an AAA asset pack. Photorealism requires production skeletal characters, animations, PBR city assets, vehicles, audio and level art inside Unreal Editor.

Start with Docs/SETUP_UE58.md and Docs/VERTICAL_SLICE.md.
